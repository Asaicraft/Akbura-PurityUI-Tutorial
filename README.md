# Akbura Purity UI Tutorial

A responsive **Purity UI dashboard** built with [Akbura](https://github.com/Asaicraft/Akbura) and [Avalonia](https://avaloniaui.net/).

This repository contains the source code from the YouTube tutorial where the dashboard is built from scratch and adapted for desktop, tablet, and mobile screen sizes.

Akbura is a component-based UI library for Avalonia that provides a concise and reactive way to build .NET user interfaces using `.akbura` components and AKCSS utilities.

## What is included

- Responsive dashboard layout
- Sidebar navigation
- Credit card component
- Money cards
- Payment methods
- Card text boxes
- Invoices
- Reusable Akbura components
- Desktop, Browser, Android, and iOS hosts

## Tech stack

- .NET 10
- Avalonia 12.0.4
- Akbura 12.0.4-beta.4
- CommunityToolkit.Mvvm
